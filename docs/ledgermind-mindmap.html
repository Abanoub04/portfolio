LedgerMind

A tiny accounting firm run only by AI agents. It turns a month of transactions into a clear expense report. Click any item with + to open it.

Build steps

  • 1Foundations
    • Lesson 1: the toolboxYou are here
    • Create a fake transactions file
    • Create a budget file
  • 2Rule-based employeesPlain Python, no AI yet
    • Collector: read and clean the file
    • Categorizer: label by keywords
    • Analyst: totals and budget check
    • Writer: fill a report template
    • Manager: run everyone in order
  • 3Give them AI brains
    • Connect Python to an AI model
    • AI Categorizer for unclear items
    • AI Writer for natural summaries
    • AI Analyst explains unusual costs
  • 4True agents
    • Each employee picks its own tools in a loop
    • Manager delegates and reviews with AI
  • 5Make it reliable
    • Check totals against the raw data
    • Handle errors without crashing
    • Log what each agent did

The Manager

  • RoleThe only agent that talks to you. Assigns work, passes results between departments, reviews the final report.
  • Tools
    • send_to_bookkeeping
    • send_to_reporting
    • review_report
  • Key skillNever trust output without checking it.

Bookkeeping dept.

  • CollectorReads and cleans the raw file
    • read_file
    • fix_dates
    • remove_duplicates
    • flag_missing_amounts
  • CategorizerLabels every transaction
    • assign_category
    • Salaries, Rent, Travel, Software, Sales…

Reporting dept.

  • AnalystTurns data into numbers
    • sum_by_category
    • compare_to_budget
    • find_unusual_costs
  • WriterTurns numbers into a readable report
    • write_summary
    • save_report
